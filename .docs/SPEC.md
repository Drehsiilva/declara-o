# Prompt para Refatoração Completa - Site de Homenagem Romântica

Atue como um **Engenheiro de Software Sênior**, **Especialista em
Front-end**, **UI/UX Designer**, **Creative Developer** e **Especialista
em Performance Web**.

Seu objetivo é **refatorar completamente este projeto existente**,
transformando-o em uma experiência moderna, cinematográfica e altamente
emocional, preservando todas as imagens originais, textos e a identidade
visual do site.

## Objetivo

Criar uma versão premium do site utilizando tecnologias modernas,
animações fluidas e efeitos imersivos, mantendo o conteúdo original,
porém elevando significativamente a experiência do usuário.

-   Mova o projeto antigo para `old/`.
-   Crie um novo projeto utilizando:
    -   Next.js (App Router)
    -   React 19+
    -   TypeScript
    -   Tailwind CSS
    -   GSAP
    -   Three.js (React Three Fiber + Drei)
    -   Framer Motion
    -   Lenis
    -   Lucide React
    -   next/image
    -   next/font

## Preservação

-   Manter todas as imagens originais.
-   Manter todos os textos.
-   Manter a ordem cronológica da homenagem.
-   Não substituir nenhuma foto.

## Direção de Design

Inspirado em Apple, Stripe, Vercel, Linear e Awwwards.

-   Layout minimalista
-   Glassmorphism discreto
-   Microinterações
-   Tipografia elegante
-   Muito espaço em branco
